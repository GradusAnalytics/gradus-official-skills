# Padrão de relatório de analytics (Gradus)

> Este arquivo é um EXEMPLO para ilustrar o formato. Substitua pelo
> conteúdo real do skill validado pelos gestores antes de publicar.

## Quando usar
Acione este skill sempre que o pedido envolver criar, revisar ou padronizar
um relatório de analytics para cliente.

## Passos
1. Confirme o período de referência e o cliente.
2. Siga a estrutura obrigatória: Resumo executivo → Metas vs. Realizado →
   Principais métricas → Recomendações.
3. Use o glossário de métricas oficial da Gradus (ver `references/`).
4. Antes de finalizar, valide contra o checklist de qualidade.
